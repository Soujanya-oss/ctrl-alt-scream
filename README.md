1. Project Titlle:
ctrl-alt-scream 


2. Project Overview:
ctrl-alt-scream is a spooky, retro-inspired interactive Halloween desktop simulator and prank engine. It fits the theme by turning a nostalgic OS environment into a haunted playground filled with custom paranormal curses, mini-games, and AI-driven spooky experiences. 


3. Tech Stack Used:
- Frontend: TypeScript, HTML, and CSS (Boo- OS 95 Retro Desktop Interface)

- Backend/Database:Client-side logic / Local runtim

- AI Models Used (e.g., Gemma, open models - if applicable): Google Gemini AI (Grimbyte AI Spirit Oracle)
                  

4. Key Features:
- Curse Control Center: Toggle paranormal    phenomena and custom desktop curses on     demand. 
- Halloween Arcade & Candy Shop: Play mini   games like Whack-a-Ghost to earn treats    and candy. 
- Grimbyte AI Spirit Oracle: Gemini-.        powered AI prank advisor and spooky        fortune-teller. 
- Stealth Prank Deployment: Deploy decoy     screens and countdown timers to prank      friends.
- Crypt Soundboard: Procedural Halloween     audio FX and synthesizer soundscapes.
  

5. How to Run / Test the App:
1. Open the deployed app using the project link.
2. Wait for the homepage to load.
3. Enter any search query in the search bar.
4. Click the search button and explore the spooky results.
5. Try different searches and interact with the app to discover hidden surprises.
